# Solidity Fallback Function

## What is a Fallback Function?

A fallback function is a special Solidity function that can run when a contract receives a call that does not match any existing function.

## Common Uses

- Handle unknown function calls
- Receive ETH in some cases
- Support proxy patterns
- Provide custom fallback behavior
- Prevent unexpected calls from failing silently

## Why It Matters

Fallback functions give smart contracts a way to respond when no regular function matches the incoming call.

## Base

Solidity fallback functions work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts handle unmatched calls.
