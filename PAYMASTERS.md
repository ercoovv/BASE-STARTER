# Paymaster Basics

## What is a Paymaster?

A paymaster is a smart contract or service that can sponsor transaction fees for users.

## Why It Matters

- Users may interact without holding ETH for gas
- Applications can create smoother onboarding
- Gas fees can be sponsored by developers
- Transactions can feel more like traditional apps

## Base

Base supports modern smart wallet and account abstraction experiences where paymasters can help sponsor gas fees.

## Learning Goal

Understand how applications can reduce friction for users by covering transaction costs.
