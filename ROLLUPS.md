# Rollup Basics

## What is a Rollup?

A rollup is a scaling technology that processes transactions outside Ethereum mainnet and then posts data or proofs back to Ethereum.

## Why Rollups Matter

- Increase transaction throughput
- Reduce transaction costs
- Keep a connection to Ethereum security
- Improve scalability

## Base

Base uses rollup technology as an Ethereum Layer 2 network.

## Learning Goal

Understand how Layer 2 networks scale Ethereum while keeping important data anchored to the main chain.
