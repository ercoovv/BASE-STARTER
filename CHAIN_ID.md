# Chain ID

## What is a Chain ID?

A chain ID is a unique identifier used to distinguish one blockchain network from another.

## Why It Matters

- Prevents transactions from being confused across networks
- Helps wallets identify the correct blockchain
- Supports safe transaction signing
- Distinguishes mainnets from testnets
- Improves network compatibility

## Base

Base Mainnet uses chain ID 8453.

Base Sepolia uses chain ID 84532.

## Learning Goal

Understand how wallets and applications identify the blockchain network they are connected to.
