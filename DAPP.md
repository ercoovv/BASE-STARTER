# DApp Basics

## What is a DApp?

A DApp is a decentralized application that interacts with a blockchain.

## Main Parts

- Frontend interface
- Wallet connection
- Smart contracts
- Blockchain network
- Onchain data

## Base

Developers can build DApps on Base using Ethereum-compatible tools and standards.

## Learning Goal

Understand how a simple application can connect a wallet and interact with a smart contract on Base Sepolia.
