# Solidity Functions

## What is a Function?

A function is a reusable block of code that performs a specific action inside a smart contract.

## Common Function Types

- Read data
- Update stored values
- Transfer assets
- Validate conditions
- Interact with other contracts

## Why Functions Matter

Functions define how users and applications interact with a smart contract.

## Base

Solidity functions work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts organize logic into reusable actions.
