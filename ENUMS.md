# Solidity Enums

## What is an Enum?

An enum is a custom Solidity type used to represent a fixed set of possible values.

## Common Uses

- Track contract status
- Represent workflow stages
- Define user roles
- Manage order states
- Store limited options

## Why Enums Matter

Enums make smart contract logic easier to read by replacing raw numbers with meaningful named states.

## Base

Solidity enums work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts represent predefined states clearly and safely.
