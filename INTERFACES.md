# Smart Contract Interfaces

## What is an Interface?

An interface defines the functions that another smart contract or application can call.

## Why Interfaces Matter

- Help contracts communicate
- Describe external functions
- Improve code organization
- Support integration between protocols
- Make reusable contract interactions easier

## Base

Smart contracts on Base use Ethereum-compatible interfaces to interact with other contracts.

## Learning Goal

Understand how smart contracts describe and use external functionality.
