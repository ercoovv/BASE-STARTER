# Transaction Nonces

## What is a Nonce?

A nonce is a number used to keep track of transactions sent from a blockchain account.

## Why Nonces Matter

- Prevent duplicate transactions
- Preserve transaction order
- Help networks verify account activity
- Support secure transaction processing

## Base

Wallets on Base use nonces just like other Ethereum-compatible networks.

## Learning Goal

Understand how blockchain accounts keep transactions unique and correctly ordered.
