# Solidity Boolean Type

## What is a Boolean?

A boolean is a Solidity data type that can hold one of two values: true or false.

## Common Uses

- Enable or disable features
- Track status
- Represent permissions
- Control contract logic
- Store yes or no conditions

## Why It Matters

Boolean values are useful for simple decision-making inside smart contracts.

## Base

Solidity boolean types work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts use true and false values to control logic.
