# Memory vs Storage

## What is Storage?

Storage is persistent data saved permanently in a smart contract's blockchain state.

## What is Memory?

Memory is temporary data that exists only while a function is executing.

## Key Differences

- storage persists between transactions
- memory is temporary
- storage operations can cost more gas
- memory is useful for temporary calculations
- choosing the correct location can improve efficiency

## Base

Solidity memory and storage rules work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how Solidity handles temporary and persistent contract data.
