# Solidity Unsigned Integers

## What is uint?

uint is a Solidity data type used to store non-negative whole numbers.

## Common Uses

- Token balances
- Counters
- Timestamps
- IDs
- Amounts

## Why It Matters

Unsigned integers are widely used in smart contracts because many blockchain values cannot be negative.

## Base

Solidity uint types work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts store and work with non-negative numeric values.
