# NFT Basics

## What is an NFT?

An NFT is a unique digital token recorded on a blockchain.

## Common Uses

- Digital art
- Collectibles
- Memberships
- Game items
- Onchain identity

## Base

Base supports Ethereum-compatible NFT standards and allows developers to build NFT applications with lower transaction costs.

## Safety

Always verify the contract and project before minting or buying an NFT.
