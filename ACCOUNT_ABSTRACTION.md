# Account Abstraction

## What is Account Abstraction?

Account abstraction is a way to make blockchain wallets more flexible and easier to use.

## Possible Benefits

- Social recovery
- Gas sponsorship
- Batched transactions
- Custom security rules
- Better user experience

## Base

Base supports modern wallet experiences that can use account abstraction concepts.

## Learning Goal

Understand how smart wallets can improve the usability of onchain applications.
