# Solidity msg.sender

## What is msg.sender?

msg.sender is a Solidity global variable that contains the address of the account or contract that called the current function.

## Common Uses

- Identify the caller
- Restrict access
- Track user actions
- Assign ownership
- Verify permissions

## Why It Matters

Smart contracts often need to know who initiated an action before allowing it to continue.

## Base

msg.sender works on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts identify the caller of a function.
