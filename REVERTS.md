# Transaction Reverts

## What is a Revert?

A revert happens when a smart contract transaction fails and its state changes are cancelled.

## Common Causes

- Failed require conditions
- Invalid function inputs
- Insufficient balance
- Unauthorized actions
- Contract logic errors

## Why It Matters

Reverts protect smart contracts from applying invalid or incomplete state changes.

## Base

Smart contracts on Base follow Ethereum-compatible revert behavior.

## Learning Goal

Understand why transactions can fail and how smart contracts protect their state.
