# Solidity Inheritance

## What is Inheritance?

Inheritance allows one Solidity contract to reuse and extend the functionality of another contract.

## Common Uses

- Reuse existing logic
- Create specialized contracts
- Share common functions
- Organize related contracts
- Reduce duplicated code

## Why It Matters

Inheritance helps developers build modular and maintainable smart contract systems.

## Base

Solidity inheritance works on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts can extend existing contract logic.
