# Solidity Constructors

## What is a Constructor?

A constructor is a special function that runs once when a smart contract is deployed.

## Common Uses

- Set the contract owner
- Define initial values
- Configure important addresses
- Initialize contract settings

## Why It Matters

Constructors help prepare a smart contract before users begin interacting with it.

## Base

Solidity constructors work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts are initialized during deployment.
