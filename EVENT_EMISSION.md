# Solidity Event Emission

## What is Event Emission?

Event emission is the process of recording structured information in a transaction log from a smart contract.

## Common Uses

- Record user actions
- Track transfers
- Notify applications
- Create activity histories
- Support blockchain indexing

## Why It Matters

Events help external applications understand what happened during a smart contract transaction without reading all contract storage.

## Base

Solidity events can be emitted on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts publish useful activity data for external applications.
