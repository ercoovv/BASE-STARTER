# Smart Wallet Basics

## What is a Smart Wallet?

A smart wallet is a wallet controlled by smart contract logic instead of only a traditional private-key account.

## Possible Features

- Account recovery
- Spending limits
- Batched transactions
- Gas sponsorship
- Custom permissions

## Why It Matters

Smart wallets can make onchain applications easier and safer to use.

## Base

Base supports Ethereum-compatible smart wallet experiences and modern account abstraction patterns.
