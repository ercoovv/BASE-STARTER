# Access Control

## What is Access Control?

Access control is a smart contract design pattern used to restrict certain actions to specific users or roles.

## Common Uses

- Admin-only functions
- Role-based permissions
- Pausing contracts
- Managing operators
- Protecting sensitive actions

## Why It Matters

Access control helps prevent unauthorized users from changing important contract settings or performing restricted operations.

## Base

Solidity access control patterns work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts can manage permissions safely.
