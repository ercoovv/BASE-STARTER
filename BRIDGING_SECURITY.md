# Bridge Security

## Why Bridge Security Matters

Blockchain bridges move assets between networks, so users should verify every step carefully.

## Basic Safety Checks

- Use official bridge interfaces
- Verify the destination network
- Check token contract addresses
- Review transaction details before signing
- Avoid unknown links and fake bridge websites

## Base

When bridging assets to or from Base, users should confirm that they are interacting with trusted infrastructure.

## Learning Goal

Understand the main risks of cross-chain transfers and how to reduce them.
