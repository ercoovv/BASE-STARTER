# Sending ETH from Solidity

## How Can a Contract Send ETH?

A Solidity smart contract can send ETH to another address using methods such as call.

## Common Uses

- Withdrawals
- Payments
- Refunds
- Revenue distribution
- Contract-to-wallet transfers

## Why It Matters

Sending ETH safely requires careful handling of failed transfers and reentrancy risks.

## Base

Contracts on Base can send ETH using the same Ethereum-compatible Solidity patterns.

## Learning Goal

Understand the basics of transferring ETH from a smart contract.
