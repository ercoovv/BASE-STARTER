# ABI Basics

## What is an ABI?

ABI stands for Application Binary Interface.

It describes how applications can communicate with a smart contract.

## What an ABI Contains

- Function names
- Function inputs
- Function outputs
- Events
- Data types

## Why It Matters

Frontends and wallets use the ABI to understand how to interact with smart contracts.

## Learning Goal

Understand how applications connect to and call smart contract functions.
