# DeFi Basics

## What is DeFi?

DeFi stands for decentralized finance.

It refers to financial applications built on blockchain networks.

## Common DeFi Activities

- Swapping tokens
- Lending assets
- Borrowing assets
- Providing liquidity
- Earning yield

## Base

Base supports Ethereum-compatible DeFi applications.

## Safety

Always understand the risks of a DeFi protocol before connecting a wallet or depositing assets.
