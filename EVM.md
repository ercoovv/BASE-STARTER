# EVM Basics

## What is the EVM?

EVM stands for Ethereum Virtual Machine.

It is the environment that executes smart contracts on Ethereum-compatible networks.

## Base and the EVM

Base is EVM-compatible, which means developers can use many of the same tools, languages and smart contract standards used on Ethereum.

## Benefits

- Solidity support
- Familiar developer tools
- Ethereum-compatible wallets
- Reusable smart contract patterns
