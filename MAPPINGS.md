# Solidity Mappings

## What is a Mapping?

A mapping is a Solidity data structure that stores values using unique keys.

## Common Uses

- Track user balances
- Store permissions
- Record ownership
- Save configuration by address
- Associate identifiers with data

## Why It Matters

Mappings make it efficient for smart contracts to organize and retrieve data.

## Base

Solidity mappings work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts associate keys with stored values.
