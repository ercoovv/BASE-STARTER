# Solidity require

## What is require?

require is a Solidity statement used to check whether a condition is true before continuing execution.

## Common Uses

- Validate user input
- Restrict access
- Check balances
- Verify permissions
- Prevent invalid state changes

## Why It Matters

If the condition is false, the transaction is reverted and the remaining code does not execute.

## Base

Solidity require statements work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts enforce important conditions before executing logic.
