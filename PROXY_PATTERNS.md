# Proxy Contract Patterns

## What is a Proxy Contract?

A proxy contract forwards function calls to another contract that contains the main logic.

## Common Uses

- Upgradeable smart contracts
- Reusable logic
- Modular contract systems
- Separate storage from implementation
- Reduce redeployment needs

## Why It Matters

Proxy patterns allow developers to change contract logic while keeping the same contract address and stored data.

## Base

Proxy patterns work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contract systems can separate user-facing addresses from implementation logic.
