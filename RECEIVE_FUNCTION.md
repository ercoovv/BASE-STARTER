# Solidity Receive Function

## What is the Receive Function?

The receive function is a special Solidity function that can accept ETH sent directly to a smart contract.

## When It Runs

- ETH is sent to the contract
- No function data is included
- The contract has a receive function defined

## Why It Matters

It allows a smart contract to safely accept direct ETH transfers.

## Base

The Solidity receive function works on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts can receive ETH without calling a named function.
