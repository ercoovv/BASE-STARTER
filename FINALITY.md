# Transaction Finality

## What is Finality?

Finality describes the point at which a blockchain transaction can be considered confirmed and extremely unlikely to be reversed.

## Why Finality Matters

- Provides confidence that transactions are complete
- Helps applications determine when actions are settled
- Reduces uncertainty for users
- Supports reliable onchain systems

## Base

Transactions on Base are processed on Layer 2 and ultimately rely on Ethereum for settlement.

## Learning Goal

Understand the difference between a transaction being processed quickly and reaching stronger settlement guarantees.
