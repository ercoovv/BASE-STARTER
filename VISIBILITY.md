# Solidity Visibility

## What is Visibility?

Visibility defines where a Solidity function or variable can be accessed from.

## Common Visibility Types

- public
- private
- internal
- external

## Why It Matters

Visibility helps control how smart contract functions and data can be used.

## Base

Solidity visibility rules work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts control access to functions and variables.
