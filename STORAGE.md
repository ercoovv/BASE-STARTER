# Smart Contract Storage

## What is Storage?

Storage is the part of a smart contract where persistent data is kept on the blockchain.

## Examples

- User balances
- Ownership records
- Configuration values
- Contract settings
- Application state

## Why It Matters

Storage data remains available between transactions and can be updated by smart contract functions.

## Base

Smart contracts on Base use Ethereum-compatible storage rules.

## Learning Goal

Understand how smart contracts keep persistent data onchain.
