# Solidity Constants

## What is a Constant?

A constant is a Solidity variable whose value is fixed directly in the contract code and cannot be changed.

## Common Uses

- Fixed configuration values
- Mathematical constants
- Limits and thresholds
- Permanent addresses
- Reusable numeric values

## Why It Matters

Constants make it clear which values are intended to remain unchanged and can also help reduce gas usage.

## Base

Solidity constants work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts define values that never change.
