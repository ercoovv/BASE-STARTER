# Solidity Basics

## What is Solidity?

Solidity is a programming language used to write smart contracts for Ethereum-compatible blockchains.

## Base

Because Base is EVM-compatible, Solidity smart contracts can be deployed on Base.

## Common Uses

- Tokens
- NFTs
- DeFi applications
- Governance systems
- Onchain games

## Learning Goal

Understand the basic structure of Solidity contracts before deploying anything on Base Sepolia.
