# CREATE2 Opcode

## What is CREATE2?

CREATE2 is an EVM opcode that allows smart contracts to be deployed to predictable addresses.

## Common Uses

- Counterfactual deployments
- Deterministic contract addresses
- Smart wallet systems
- Factory contracts
- Advanced deployment patterns

## Why It Matters

CREATE2 makes it possible to know a contract address before the contract is actually deployed.

## Base

Base supports Ethereum-compatible EVM opcodes, including CREATE2.

## Learning Goal

Understand how deterministic contract deployment works on Ethereum-compatible networks.
