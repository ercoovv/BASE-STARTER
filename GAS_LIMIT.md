# Gas Limit

## What is a Gas Limit?

A gas limit is the maximum amount of computational work a transaction is allowed to use.

## Why It Matters

- Prevents transactions from using unlimited resources
- Helps wallets estimate transaction requirements
- Protects users from unexpected execution costs
- Supports predictable transaction processing
- Helps smart contracts execute safely

## Base

Transactions on Base use Ethereum-compatible gas limits.

## Learning Goal

Understand how gas limits control the maximum computational cost of a transaction.
