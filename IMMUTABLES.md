# Solidity Immutable Variables

## What is an Immutable Variable?

An immutable variable is a Solidity variable that can be assigned once during contract creation and cannot be changed afterward.

## Common Uses

- Store important addresses
- Save deployment settings
- Define permanent configuration
- Reduce unnecessary storage changes
- Improve gas efficiency in some cases

## Why It Matters

Immutable variables are useful when a value should remain fixed for the lifetime of a smart contract.

## Base

Solidity immutable variables work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts can store values that are fixed after deployment.
