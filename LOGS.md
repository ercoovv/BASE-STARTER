# Blockchain Logs

## What are Logs?

Logs are records created by smart contracts during transaction execution.

## Common Uses

- Track contract activity
- Record transfers
- Store event information
- Help applications update interfaces
- Make onchain activity easier to index

## Why Logs Matter

Applications can read logs without scanning all contract storage.

## Base

Smart contracts on Base can emit logs through Solidity events.

## Learning Goal

Understand how applications track smart contract activity efficiently.
