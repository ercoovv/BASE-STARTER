# Function Modifiers

## What is a Modifier?

A modifier is a Solidity feature used to add reusable conditions to smart contract functions.

## Common Uses

- Restrict access
- Check permissions
- Validate inputs
- Pause contract actions
- Reuse common rules

## Why Modifiers Matter

Modifiers help keep smart contract code cleaner and reduce repeated logic.

## Base

Solidity modifiers work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts can apply reusable rules before functions execute.
