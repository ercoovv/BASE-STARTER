# Solidity Custom Errors

## What are Custom Errors?

Custom errors are a Solidity feature used to define specific error types for failed contract operations.

## Why Use Custom Errors?

- Provide clearer failure reasons
- Reduce repeated error strings
- Can use less gas than long revert messages
- Improve contract readability
- Make debugging easier

## Base

Custom errors work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts can report failures efficiently and clearly.
