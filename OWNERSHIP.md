# Contract Ownership

## What is Ownership?

Ownership is a common smart contract pattern where a specific address has permission to perform restricted actions.

## Common Uses

- Update contract settings
- Pause or resume features
- Manage authorized addresses
- Transfer administrative control
- Protect sensitive functions

## Why It Matters

Ownership helps separate normal user actions from administrative actions.

## Base

Ownership patterns used in Solidity work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts can restrict important actions to authorized accounts.
