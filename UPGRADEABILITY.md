# Smart Contract Upgradeability

## What is Upgradeability?

Upgradeability is the ability to change smart contract logic after deployment while preserving important state and addresses.

## Common Reasons

- Fix bugs
- Add new features
- Improve contract logic
- Adapt to protocol changes
- Maintain long-lived applications

## Why It Matters

Because deployed smart contracts are normally immutable, upgradeable designs use special patterns to separate storage from implementation logic.

## Base

Upgradeable Solidity patterns can be used on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contract systems can evolve after deployment.
