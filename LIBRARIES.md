# Smart Contract Libraries

## What is a Library?

A library is reusable code that can be shared across smart contracts.

## Why Libraries Matter

- Reduce duplicated code
- Improve maintainability
- Organize common logic
- Support reusable functions
- Help keep contracts cleaner

## Base

Solidity libraries can be used in smart contracts deployed on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how reusable code can make smart contract development more efficient.
