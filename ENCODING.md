# Data Encoding

## What is Encoding?

Encoding is the process of converting information into a format that computers and smart contracts can understand.

## Common Examples

- Addresses
- Numbers
- Strings
- Function calls
- Transaction data

## Why It Matters

Ethereum-compatible networks use standardized encoding rules so wallets, applications, and smart contracts can communicate correctly.

## Base

Base follows Ethereum-compatible encoding standards for transactions and smart contract interactions.

## Learning Goal

Understand how human-readable information is transformed into blockchain-compatible data.
