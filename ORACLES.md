# Blockchain Oracles

## What is an Oracle?

An oracle provides external data to smart contracts.

## Common Uses

- Asset prices
- Weather data
- Sports results
- Exchange rates
- Real-world events

## Why Oracles Matter

Smart contracts cannot directly access information outside the blockchain, so oracles help bring external data onchain.

## Base

Applications built on Base can use oracle services to access external data securely.

## Learning Goal

Understand how smart contracts can use reliable offchain information.
