# Smart Contract Bytecode

## What is Bytecode?

Bytecode is the low-level code produced when a smart contract is compiled.

## Why It Matters

- It is deployed to the blockchain
- The EVM executes it
- It represents the compiled contract logic
- It differs from the human-readable Solidity source code

## Base

Smart contracts deployed on Base are compiled into EVM-compatible bytecode.

## Learning Goal

Understand the difference between Solidity source code and the bytecode executed onchain.
