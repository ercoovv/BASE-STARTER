# Solidity Bytes Type

## What is bytes?

bytes is a Solidity data type used to store dynamically sized byte sequences.

## Common Uses

- Encoded data
- Function call data
- Hashes
- Signatures
- Raw blockchain information

## Why It Matters

The bytes type is useful when smart contracts need to handle compact binary data rather than human-readable text.

## Base

Solidity bytes types work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts store and process raw byte data.
