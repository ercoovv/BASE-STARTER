# OP Stack Basics

## What is the OP Stack?

The OP Stack is a collection of open-source components used to build Ethereum Layer 2 networks.

## Why It Matters

- Provides modular blockchain infrastructure
- Supports Ethereum compatibility
- Helps Layer 2 networks scale
- Encourages shared standards

## Base

Base is built using the OP Stack.

## Learning Goal

Understand the infrastructure that powers Base and other Ethereum Layer 2 networks.
