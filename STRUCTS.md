# Solidity Structs

## What is a Struct?

A struct is a custom data type in Solidity that groups related values together.

## Common Uses

- Store user profiles
- Group configuration values
- Represent items or records
- Organize contract data
- Combine multiple fields into one object

## Why Structs Matter

Structs make smart contract data easier to organize and understand.

## Base

Solidity structs work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts can group related information into custom data structures.
