# Calldata Basics

## What is Calldata?

Calldata is the encoded information sent with a blockchain transaction when calling a smart contract function.

## What It Can Contain

- Function selectors
- Function arguments
- Addresses
- Numbers
- Encoded text
- Other contract input data

## Why It Matters

Smart contracts read calldata to understand which function should run and which values were provided.

## Base

Transactions on Base use Ethereum-compatible calldata when interacting with smart contracts.

## Learning Goal

Understand how information is passed from a wallet or application to a smart contract.
