# Solidity Fixed-Size Arrays

## What is a Fixed-Size Array?

A fixed-size array is a Solidity array whose length is defined when the variable is declared.

## Common Uses

- Store a known number of values
- Keep compact collections
- Represent fixed configuration sets
- Work with predictable data structures
- Reduce unnecessary dynamic resizing

## Why It Matters

Fixed-size arrays are useful when a smart contract always needs to store the same number of related values.

## Base

Solidity fixed-size arrays work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand the difference between fixed-size and dynamic arrays in Solidity.
