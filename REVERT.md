# Solidity revert

## What is revert?

revert is a Solidity statement used to stop execution and undo state changes when a specific condition or error occurs.

## Common Uses

- Reject invalid operations
- Return custom error messages
- Stop unauthorized actions
- Handle complex validation logic
- Protect contract state

## Why It Matters

revert gives developers more control over when and why a smart contract transaction should fail.

## Base

Solidity revert behavior works on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts intentionally stop execution and roll back invalid changes.
