# Blockchain State

## What is Blockchain State?

Blockchain state represents the current data stored by the network.

## Examples

- Wallet balances
- Smart contract variables
- Token ownership
- Contract storage
- Account information

## Why State Matters

Every valid transaction can change the blockchain state.

## Base

Applications on Base read and update network state through transactions and smart contract interactions.

## Learning Goal

Understand how blockchain data changes over time as transactions are processed.
