# Solidity Dynamic Arrays

## What is a Dynamic Array?

A dynamic array is a Solidity array whose size can grow or shrink during contract execution.

## Common Uses

- Store changing lists of addresses
- Track user records
- Maintain collections
- Add new items over time
- Remove or update stored entries

## Why It Matters

Dynamic arrays are useful when a smart contract does not know in advance how many values it will need to store.

## Base

Solidity dynamic arrays work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts manage collections whose size can change over time.
