# Governance Basics

## What is Governance?

Governance is the process used to make decisions about protocols, communities, or blockchain ecosystems.

## Common Governance Activities

- Voting on proposals
- Suggesting protocol changes
- Managing community resources
- Setting technical priorities
- Coordinating ecosystem decisions

## Onchain Governance

Some blockchain projects use smart contracts and tokens to record votes and execute approved decisions.

## Learning Goal

Understand how decentralized communities can coordinate decisions transparently.
