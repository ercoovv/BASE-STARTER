# Blockchain Blocks

## What is a Block?

A block is a collection of blockchain transactions grouped together and added to the network.

## What Blocks Contain

- Transactions
- Timestamps
- Network data
- References to previous blocks
- State updates

## Why Blocks Matter

Blocks help organize blockchain activity into a verifiable history.

## Base

Base processes transactions in batches and records resulting state changes as part of its Layer 2 operation.

## Learning Goal

Understand how blockchain activity is grouped and recorded over time.
