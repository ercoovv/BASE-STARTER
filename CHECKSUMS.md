# Address Checksums

## What is a Checksum?

A checksum helps detect mistakes in blockchain addresses by using a standardized letter capitalization format.

## Why It Matters

- Helps reduce address typing errors
- Makes wallet addresses easier to verify
- Improves transaction safety
- Supports Ethereum-compatible tools

## Base

Base uses Ethereum-compatible address formats, including checksum conventions.

## Learning Goal

Understand how checksum formatting helps users verify blockchain addresses more safely.
