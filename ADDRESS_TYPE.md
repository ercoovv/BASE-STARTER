# Solidity Address Type

## What is an Address?

An address is a Solidity data type used to store Ethereum-compatible account or contract addresses.

## Common Uses

- Store wallet addresses
- Track contract owners
- Identify external contracts
- Send ETH
- Manage permissions

## Why It Matters

Addresses are one of the most important data types in smart contracts because most onchain interactions involve users or other contracts.

## Base

Base uses Ethereum-compatible addresses, so Solidity address types work the same way.

## Learning Goal

Understand how Solidity represents and uses blockchain addresses.
