# Solidity State Mutability

## What is State Mutability?

State mutability describes whether a Solidity function reads from or changes blockchain state.

## Common Types

- view
- pure
- payable
- nonpayable

## Why It Matters

State mutability helps developers understand how a function interacts with contract data and whether it can receive ETH.

## Base

Solidity state mutability rules work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand the difference between functions that read state, modify state, and receive value.
