# Solidity String Type

## What is a String?

A string is a Solidity data type used to store human-readable text.

## Common Uses

- Names
- Messages
- Metadata
- Labels
- Descriptions

## Why It Matters

Strings allow smart contracts to store and return readable text for users and applications.

## Base

Solidity strings work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts store and use text data.
