# Solidity assert

## What is assert?

assert is a Solidity statement used to check conditions that should always be true during correct contract execution.

## Common Uses

- Verify internal invariants
- Detect unexpected contract states
- Validate assumptions in contract logic
- Catch programming errors
- Protect important internal rules

## Why It Matters

If an assert condition fails, the transaction reverts because the contract has reached an unexpected state.

## Base

Solidity assert statements work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts detect conditions that should never fail during normal operation.
