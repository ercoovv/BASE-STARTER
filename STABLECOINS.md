# Stablecoin Basics

## What is a Stablecoin?

A stablecoin is a token designed to maintain a relatively stable value, often linked to a currency such as the US dollar.

## Common Uses

- Payments
- Trading
- Saving value onchain
- DeFi applications
- Cross-border transfers

## Base

Stablecoins can be used across many applications built on Base.

## Safety

Always verify the token contract and understand the issuer before using a stablecoin.
