# Solidity Arrays

## What is an Array?

An array is a Solidity data structure used to store multiple values of the same type.

## Common Uses

- Store lists of addresses
- Track identifiers
- Keep collections of numbers
- Save groups of related values
- Manage ordered data

## Why Arrays Matter

Arrays help smart contracts organize multiple pieces of related information.

## Base

Solidity arrays work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts store and work with ordered collections of data.
