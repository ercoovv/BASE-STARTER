# Block Timestamp

## What is a Block Timestamp?

A block timestamp is the time value associated with a blockchain block.

## Common Uses

- Time-based conditions
- Expiration dates
- Delayed actions
- Vesting logic
- Scheduled contract behavior

## Why It Matters

Smart contracts can use block timestamps to make decisions based on time.

## Base

Base smart contracts can access block timestamps using Ethereum-compatible Solidity features.

## Learning Goal

Understand how smart contracts use blockchain time information.
