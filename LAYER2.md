# Layer 2 Basics

## What is Layer 2?

Layer 2 networks are built on top of Ethereum to improve scalability and reduce transaction costs.

## Why Layer 2 Matters

- Lower fees
- Faster transactions
- Better scalability
- Easier access to onchain applications

## Base

Base is an Ethereum Layer 2 network designed to support scalable onchain applications while remaining connected to the Ethereum ecosystem.
