# Solidity Payable Functions

## What is Payable?

A payable function is a Solidity function that can receive ETH when it is called.

## Common Uses

- Accept payments
- Receive deposits
- Fund contracts
- Collect fees
- Support payable interactions

## Why It Matters

Without the payable keyword, a Solidity function cannot normally receive ETH directly.

## Base

Payable Solidity functions work on Base just like on other Ethereum-compatible networks.

## Learning Goal

Understand how smart contracts receive ETH through payable functions.
