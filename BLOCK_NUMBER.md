# Block Number

## What is a Block Number?

A block number identifies the position of a block within a blockchain.

## Common Uses

- Track blockchain progress
- Reference historical activity
- Trigger block-based logic
- Compare state changes
- Identify when transactions were included

## Why It Matters

Block numbers provide a simple way to organize and reference blockchain history.

## Base

Base smart contracts can access block information using Ethereum-compatible Solidity features.

## Learning Goal

Understand how smart contracts and applications reference blockchain history using block numbers.
